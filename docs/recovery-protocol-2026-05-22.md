- [ ] **Pee** — first thing after wake
- [ ] **Naked weigh-in** — log weight (track trend, not single day)
- [ ] **500 ml plain water immediately** — overnight dehydration carryover
- [ ] **Get outside / open window — sunlight on eyes 10-20 min**
  - Why: anchors circadian rhythm, suppresses excess morning cortisol, sets sleep timer for tonight
  - Even cloudy daylight works (don't need direct sun)
  - Phone-free if possible
- [ ] **Orthostatic test** (optional but valuable on rest days)
  - Sit relaxed 2 min → record → stand 2 min → record

- [ ] **Bazaar walk / outdoor light movement** — 15-30 min

  - Side benefit: light Achilles loading without stress

## 🔬 SCIENCE BEHIND IT (for the curious)

### Why these biomarkers tell us what they tell us

**RMSSD / HF power** → parasympathetic tone, fastest-responding HRV metric. Reflects last 24-48h.

**LF/HF** → autonomic balance index. NOT a clean sympathetic/parasympathetic ratio (Heathers 2014) but tracks stress empirically. Use as trend over days.

**DFA α1** → fractal scaling of heart rhythm. Healthy ~1.0. Drops below 0.75 during high intensity (Rogero 2021 — future LT1 marker). Stays elevated >1.2 with chronic stress.

**VLF power** → very slow oscillations. Elevated in sleep apnea, fragmented sleep, chronic stress. SAMSUNG SpO2 drop event 3 days ago supports apnea-pattern hypothesis.

**Sample entropy** → complexity/irregularity. Low = rigid system (chronic stress signature). Higher = flexible.

**CAR** → cortisol awakening response. HR/HRV inflection in first 30-45 min post-wake. Exaggerated (>50 bpm) = HPA-axis hyper-reactivity from chronic stress.

**TSB** → training stress balance. Coggan model: CTL (fitness, 42d EWMA) − ATL (fatigue, 7d EWMA). Below -20 = significant fatigue.

### Recovery mechanisms (why each protocol item works)

- **Sleep** → glymphatic clearance + GH/testosterone restoration + muscle protein synthesis + autonomic reset. Single biggest lever.
- **Sunlight (morning)** → suprachiasmatic nucleus anchoring → cortisol rhythm normalization → better sleep tomorrow.
- **Delayed coffee** → respects natural cortisol curve, prevents adenosine receptor over-saturation.
- **Paced breathing** → vagus nerve direct stimulation via baroreflex coupling, acutely raises HF power.
- **Cold exposure** → cold-shock norepinephrine then strong parasympathetic rebound.
- **Magnesium** → cofactor in 300+ enzymes including those regulating vagal tone, GABA synthesis (sleep), and muscle relaxation.
- **Strict Z1** → builds mitochondrial density + parasympathetic tone without sympathetic activation.
- **Stretching** → reduces sustained muscular sympathetic input.
